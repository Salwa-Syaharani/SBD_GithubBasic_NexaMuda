
# Project Instructions

## Project Overview
This repository contains a personal portfolio website.

## Development Guidelines
- Preserve existing portfolio content.
- Use semantic HTML.
- Keep CSS organized and reusable.
- Use JavaScript only when needed for interactive features.
- Maintain responsive layouts for mobile, tablet, and desktop.
- Avoid adding dependencies without a clear reason.
- Do not deploy or push changes unless explicitly requested.

## Validation
- Check browser console errors.
- Test navigation and interactive elements.
- Verify responsive layouts.
- Explain changed files after every implementation task.
